# Transformer Mastery — Project Track

Four end-to-end Jupyter notebooks:

1. Attention Visualizer
2. Transformer Classifier
3. Mini Language Model
4. Mini GPT

## Setup

```bash
pip install torch numpy matplotlib jupyter
```

Then launch:

```bash
jupyter notebook
```

## Suggested order

Run notebooks in numerical order. Each one assumes only the concepts established before it and is designed to be executable from a fresh kernel.

## Quality principles

- Explicit architecture before abstraction
- Reproducibility via fixed seeds
- Shape/probability sanity checks
- Training and validation curves
- Inference/generation
- Interpretation and limitations
